# 离线字体试排与网格校样

工具位于 `assets/proof-tool/`，从实际使用过的试排页提炼，不包含某套字体或对原项目的依赖。2.0 保留离线试排，并增加可选的本地[钢笔与轮廓编辑](glyph-editor.md)；校样辅助层和真实轮廓修改分别处理。

## 两种使用方式

**直接试排现成文件：**复制整个目录，浏览器打开 `index.html`，点“载入字体”导入本机 TTF、OTF、WOFF 或 WOFF2。未载入时显示明确标记的系统示例；没有假称为新设计的默认字体。

**随当前字体交付：**使用项目中已有 fontTools 的 Python：

```bash
python /absolute/path/to/hunter-font-design/scripts/create_proof.py "/project/fonts/Family-Heavy.ttf" "/project/proof-v001"
```

脚本复制工具和字体原件，生成 `font-config.js` 与 `font-info.json`；字体不改写、不安装、不上传。后者记录名称、版本、SHA-256、原 UPM、完整 Unicode cmap、参考线来源、部分字符的真实轮廓边界/占位，以及已声明的特性。目标须是新目录；重新导出后生成新的版本目录，不覆盖已有审校证据。

生成与编辑依赖 Python + fontTools；WOFF2 解析还取决于 Brotli。普通试排不需要 Python、服务器或联网；读取/回写轮廓时使用随包 `打开字体编辑器.command` 或 `editor-runtime/serve_editor.py` 启动本地服务。字体合集不由该导入器直接选择 face；按项目要求另行导出要审的单个 face。

随项目交付时，把该项目副本的默认文字、标题/段落/字符预设换成目标语言和用途，并逐码点检查预设都在当前 cmap 内。中文项目应包含中文连续标题、密集字与中英数字标点混排；浏览器能回退显示不算字体覆盖。默认生成器和通用检查仍有拉丁样例，须增加相应中文的真实字面/占位、加载字节与网格验证，不能只跑英文交互检查就声称中文试排通过。只改项目副本，不把某个项目的样字固定到共享模板。

## 交付时展示试排预览

- 最终回复将“打开试排预览”与字体下载包、技术册等入口一起列出，直接链接到本轮可用的试排 HTML 或实际预览地址。桌面本地文件使用可点击的绝对路径，不链接 ZIP 内部路径，也不只给目录名。
- 客户端支持应用内浏览器／预览面板时，用对应能力打开该页供用户试排，并保留文字链接方便再次进入。若只返回排队状态，不宣称页面已打开；不支持预览的环境说明如何在浏览器打开本地 HTML。
- 交付前确认入口存在、页面实际载入当前家族／样式／版本，字体字节与本轮交付哈希一致。已有成稿仅复查且字体未变时，可复用同哈希的试排页；字体改变后更新入口与配置。
- 默认沿用本地离线预览；公开部署按本次授权另行处理。静态截图可作辅助，不能替代可输入文字的试排页。

## 公众号与制作署名

猎人品牌试排工具默认随包携带用户提供的原版 logo 与公众号二维码（`brand/`），由 `brand.css` 和 `brand.js` 在页面打开时展示。侧栏新增区域**只放公众号二维码，以及下方一行「Created by AIGC创意猎人」**。不追加版权详情、许可文案、关注提示或其他说明。字体内版权和许可信息仍按原封装流程处理，此处署名不构成许可声明。

桌面把这一区域放在左栏底部，参数区独立滚动；小屏在参数前展示。二维码保留完整白边与正方形比例，不裁剪、重绘或外链；用原文件哈希核对，并实际查看桌面、矮屏和手机布局。其他客户的交付按该项目品牌替换素材和工具署名，不混用猎人公众号。

更新既有交付时同步每个试排副本、随包资源、清单与嵌套 ZIP，字体二进制和原版权许可保持不变。验收首次打开可见、扫码图像完整，以及切换、导入、重置、网格校样和离线打开。

## 交互

- 自由试排：任意文字；字号、行距、字间距、段距、文本宽度；对齐；字偶/标准连字开关；标题/段落/字符样本。换行分行、空行分段。
- 网格：主/次网格、基线、大写线、小写线、上伸/下伸参考线，字面框与边距；同一 em 缩放和坐标，不按字单独拉伸。字号控制放大。
- 每个已覆盖字形的网格右下角默认提供圆形放大镜图标按钮：32 px 圆形、18 px 图标，悬停提示“放大”，保留逐字可访问名称。点击打开悬浮校样，使用当前真实字形、参考线和图层，至少按原字号两倍放大；大字可在浮层内滚动查看。关闭按钮、Esc 或空白处关闭后返回原按钮；更新字形或模式时关闭旧浮层。缺字不生成假的放大校样。
- 模式切换保留排版参数。网格内停用段落/字距等无意义的控件，字偶与连字回自由试排检查。
- 重置保留当前字体；无效导入保留之前字体。下载保存原始选中文件，不改变格式或许可。
- 桌面视口固定顶部与控制区域，左侧参数、字样区各自滚动；滚到末尾仍能调整字号和参考线。矮屏让左侧和过高的网格设置可独立滚动，保留字样查看空间。手机采用上下流式布局，避免固定面板遮住全部内容。

- 文本宽度默认铺满当前可用区域，并随窗口、分屏和侧栏变化双向适配；不能只在变窄时限幅、放大后仍停在手机宽度。用户手动设定的宽度需保留，窄窗临时限幅后再放大应恢复；拖至最大值或重置恢复自动铺满。检查首次窄窗打开后变宽、宽→窄→宽、手动宽度恢复和重置，不能只看互不关联的桌面/手机截图。

## 精确度与边界

几何真边界保存在 font-info.json 的 bounds；browserBounds 单独保存浏览器对照字框：TrueType 读取轮廓表字框及边距，CFF 采用控制点包围框，与本工具已验证的 Chrome/CoreText 读数对照。两种口径分开保存，不能用浏览器字框覆盖精确轮廓边界。

所有网格值按 **1 em = 1000 u** 显示。脚本读取字体表/控制字轮廓后归一参考线，并逐项记录来源；上伸/下伸参考字的轮廓范围不等于整套字体的行距指标。浏览器显示的单字边界和边距仍是 CanvasTextMetrics 测量，不是轮廓节点编辑坐标。

脚本配置的默认字体有真实 cmap，网格会标记缺字；临时通过文件选择导入的字体未解析 cmap，必须明示可能回退。自由试排的缺字也可能由系统回退，不能用显示成功证明覆盖。网格按码点去重、忽略空白；附标组合、连字、复杂文字、可变轴以及空格行为须在字体工程与自由试排中另验。当前工具不提供轴滑块或完整 OpenType 控制面板。

参考线、网格和试排参数只影响显示；不改源轮廓、hmtx、GPOS 或字体文件。只有进入 2.0 编辑器并导出才生成带轮廓/占位修改的新字体；GPOS 字偶仍回源处理。工具支持不同字体，不把某套字体的 700/520 高度或方正造型固定为通则。

TrueType 的浏览器字面测量可能使用 `glyf` 包围盒并叠加 `hmtx` 左边距，而不是贝塞尔曲线的精确极值。生成器在 `probeMetrics` 中同时保留精确 `bounds` 和用于浏览器核验的 `browserBounds`；非 `glyf` 字体沿用曲线边界。检查脚本应对照对应数据，不能把两种边界的正常差别误判为字体错位，也不能因此放宽所有轮廓的检查误差。

## 验证工具与缓存

网格脚本与样式按文件内容添加哈希参数，确保交互升级后读取新资源；字体哈希与 UI 资源哈希分别核对。

自动化环境有 Playwright 和 Chrome 时：

```bash
node /absolute/path/to/hunter-font-design/scripts/check_proof.cjs "/project/proof-v001"
```

它验证默认字体实际加载/下载字节、测量与源度量、同尺度网格、主要输入与模式交互、错误导入保护、缺字、离线行为、桌面两种模式滚动时控制区不移动、矮屏控件可达性、移动端溢出，并保存截图与 JSON 报告。优先复用环境已有依赖；否则用可用浏览器逐项操作，不为截图测试新装整套依赖。

`document.fonts.check()` 或“加载完成”不能单独排除缓存。比对浏览器取得的字体 SHA-256 与交付文件，并在关闭 kern/连字的单字符测量中核对真实占位；复杂字符串需要实际塑形结果。系统安装后的同名缓存另行检查。

生成的 `font-config.js` 与字体 URL 都带当前字体的哈希参数，防止同一路径更新版本时仍使用旧配置。只给 HTML 或字体加版本号不够；保留生成器写入的配置 URL，项目定制只改样字与预设，不能整页复制旧配置引用。

控制字源稿可使用 2.0 钢笔工具或项目原有字体编辑器绘制；手改保留哈希绑定的 JSON 补丁与原字体，可重复应用，不能只保留一张 SVG 或截图。有真实导出后核对导出与排版。工具通过不等于设计已获确认，也不等于安装和跨应用验证已完成。
