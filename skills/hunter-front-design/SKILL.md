# 猎人字体设计 · Hunter Front Design

把风格要求变成可复查的轮廓规则，再变成真实字体。网格、样张、字体文件和试排页面都必须指向同一版本；概念图不能冒充字体文件的实际效果。

## 开始与范围

- 先读现有设计依据、源文件、确认记录和构建方法。区分已认可母版、候选参数、已被替代方案；不能为了迁就旧轮廓反写规范。
- 新项目明确用途、目标字号、语言与字符清单、字重/字宽、平台和交付格式。先做用户要的范围，不把单字重自动扩成多字重或多语种家族。“完整”指约定字符与功能，不指整个 Unicode。
- 本 skill 的已验证操作以拉丁字体为主。其他文字、复杂塑形、可变字体或彩色字体沿用原则与审校框架，但要增加相应文字和格式的专门设计验证，不能宣称当前工具已覆盖。
- 复用已有确认，不重复问许可。新设计按下节先选样；“做完整字体”本身不等于已选方案。用户选定后按授权推进，将尚未确认的细节标为候选。工程通过不等于审美获批。

## 0. 确认风格，再提供三案选样

新字体设计的默认顺序是：**需求 → 确认风格 → 三种初步效果 → 用户选定 → 设计规则与真实控制字 → 扩字、封装与试排**。

1. **确认风格**：用简短问题或选项明确用途与风格倾向；用户已经明确的风格直接沿用，不重复确认。风格确定后仍要提供三案，不能把风格词当成已经选定的字形方案。
2. **实际生成三案**：使用可用的图像生成能力，返回 A/B/C 三张初步字体概念效果图，不以三段文字描述代替。三案都遵守已确认的风格，在骨架比例、字宽、曲率、端头或字形性格上形成可见区别；不靠更换背景、颜色或场景充数。此时只做足以判断方向的样字，不提前制作三套完整字库。
3. **让三案可比较**：使用相同样字和短语、相同画幅与简洁背景、接近的可见字高；按任务覆盖必要的大小写、数字或特殊结构，不为凑比较扩大字符范围。逐张检查样字是否清楚、是否确有差异，修正乱码或缺字后再展示。每案附一两句说明，指出主要差异与适用气质。
4. **等待选定**：明确标注“概念效果，尚非可安装字体”，邀请用户选 A/B/C，也可明确组合某些特征或要求重做。可以推荐并说明理由，但用户选定前停在选样阶段，不自行替选后批量扩字。普通的完整制作授权不跳过此步骤；用户明确要求跳过选样或授权代选时，说明采用的方向后继续。
5. **落实所选方向**：保存三案、所选编号及用户要求保留的特征，再进入下列设计规则、真实轮廓网格和控制字验证。把概念效果转化为可实现的几何规则；生成图不证明字符覆盖、字距或字体工程已完成。

已有用户选定的方案或认可母版时沿用记录；局部修字、继续扩字、补封装或追加应用海报不重新开启三选一。用户明确要求重新探索设计方向时才回到此阶段。

## 1. 先写设计原则

用 [设计规则模板](assets/design-rules-template.md) 在项目中建立规则表。每项写明：**风格意图 → 结构约束/候选数值 → 控制字 → 检查方式 → 光学例外与确认状态**。

必须先考虑：

- em/UPM、基线、大写线、x-height、上下伸部、超出补偿、网格单位。
- 字宽分组与宽高比；区分字面宽、占位宽、笔画等重和等宽字体。比例字不强制 I/M 同宽，等宽数字也不要求每个数字的黑色字面同宽。
- 竖横笔画、曲线/斜笔重量、交汇减重；端头、切角、衬线或无衬线规则。
- 外轮廓的平直段、侧壁、转角起止和切向；内白的形状、面积、内角与最窄处；开口位置、方向与目标尺寸下的可读性。
- 大小写、数字、标点、货币/数学/编辑符号、附标的相互关系；边距、重心、视觉居中与行距余量。

内外圆角不是简单套同一半径，也不一定等于“外半径减笔画厚度”。用同组母字比较转角附近的黑度、内白和直线长度。统一的是造型逻辑，光学校正可不同。方正、短转角只是某些项目的风格，不是本 skill 对所有字体的默认造型。

## 2. 网格控制字先于批量扩字

读 [结构分组与反复修订经验](references/design-review.md)，选覆盖直线、碗部、斜线、交叉、开口、腰部、肩部、上下伸部的控制字。可从 `H O B D P R C G Q S N X / n o a e g m r s u / 0 2 5 6 8 9 / & ? €` 取样，不固定数量。

1. 有参考的字符逐个标出来源；没有直接参考的标为规则推导。既有参考不只比较最显眼的一个单词。
2. 选样后的第一版源轮廓就出**源轮廓网格板**：相同 em 缩放、坐标和基线，保留真实字宽；标出参考线、字面框、占位与边距。初步概念图不冒充源轮廓；位图只有估测坐标时直说。
3. 同时出无网格单字、真实单词及目标字号。大图看接缝，实际字号看黑白节奏；必要时反白检查。
4. 记录问题属于哪条规则。允许超出、交汇减重、S 的上下不对称等光学例外；不以所有节点吸附、机械对称或像素相似率当验收。
5. 源稿形成后尽早导出小范围真实试验字体，用配套工具核对“参考 → 源轮廓 → 导出效果”。明确阶段后再扩展，不用好看的生成图替代此链路。

## 3. 扩展整套字符并维持统一

- 先列具体码点、字形与语言，再按结构组扩展：直线、闭合碗部、开口、斜笔、S/8 类；小写、数字和符号各自成组。小写不是缩小的大写，数字不是套现成圆体。
- 母字与共享部件保留依赖清单，例如 `O → Q/Ø/Ò…`、`S → Š/$/§`、`C → Ç/€`。依赖只是复查范围，不代表机械复制：€ 需要横杠出口，§、&、ß、æ/œ 常需独立处理。
- 每轮保存旧版，写实际修改范围和要保护的字形。修改共享规则后查所有派生字；确认“未变”用轮廓/度量/塑形数据比较，不能只比文件大小或字偶数量。
- 用 `Ss O0o B8b Dd Pp Qq Rr Uu` 等跨组同排检查家族感；全字符逐字翻页查漏，再看混排。保留 ©/® 外框、括号等必要语义结构，不把“统一”做成所有符号同形。
- 一轮反馈先修根因并核对影响，避免只修箭头指向的一点。已认可部分作为保护基线；若必须连带改变，说明具体原因和差异。

## 4. 工程、封装与安装验证

到导出阶段读 [工程与字体封装](references/engineering-packaging.md)。保留可编辑源和可重复构建方式；先边距后字偶，再验证实际需要的 OpenType 特性。TTF/OTF 必须真实编译，网页包装不能代替轮廓转换。

按用途交付 TTF/OTF、WOFF2/WOFF；TTC/OTC、可变字体、彩色或旧式格式只在需要时增加专门检查。核对内部命名、版本、家族/样式关系、编码、度量、嵌入设置、实际轮廓类型和容器。建立文件清单与校验值，解压回读后再交付。

分开报告四类证据：

| 关卡 | 完成证据 |
| --- | --- |
| 设计 | 规则、同尺度网格、无网格样张、全字符审校、确认与例外记录 |
| 字体结构 | 真实导出、编码/轮廓/度量检查、工程报告和未解决警告 |
| 塑形与试排 | 字偶/连字/附标实际结果、目标字号、大小写数字符号混排与缺字说明 |
| 平台与封装 | 容器回读、包内文件一致性、实际执行的安装/注册/应用验证 |

字体能被解析、浏览器能显示、进程内注册成功、系统已安装、目标软件兼容是不同事实。说明实际做到哪层，不把审校稿称为正式发行版。

## 5. 把试排工具作为每轮交付的一部分

读 [试排工具用法与边界](references/proof-tool.md)。可直接复制 `assets/proof-tool/` 离线导入字体；有构建字体时，优先运行：

```bash
python /absolute/path/to/hunter-front-design/scripts/create_proof.py "/project/fonts/Family-Heavy.ttf" "/project/proof-v001"
```

输出是完整本地工具，包含当前字体原件、真实 cmap、度量来源与 SHA-256。目标目录须不存在，防止覆盖旧审校证据。用项目已有含 fontTools 的 Python 环境运行；不依赖 SOLID A 目录。

自由试排提供输入、字号、行距、字间距、段距、宽度、对齐、字偶和连字开关；网格校样提供网格/参考线/边距辅助层。桌面滚动字样时，顶部、左侧和网格参数保持可操作；小屏另验可达性。修改辅助线不改变轮廓，实际字距修正应回到字体源。

交付前核对页面实际载入和下载的字节、字体版本与哈希，排除旧缓存；验证主要交互和实际字号。自动化可用时运行 [浏览器检查脚本](scripts/check_proof.cjs)，否则用当前可用浏览器操作并记录证据。不要为了工具截图重新设计页面。

## 6. 完成后可选：字体宣传展示

字体设计、封装与试排交付完成后，询问用户是否需要技术展示海报和应用场景海报；**默认不自动生成**。用户已明确要求时直接执行，不再次问许可。数量、比例、主题与用途服从本次要求，不把某个项目的 8+8 张或 3:4 固化成通用默认值。

制作时读 [宣传海报流程](references/promotion-posters.md)：先规划各张的展示目的和版式差异，再用真实字体排出主文字；生成图只提供场景素材。画幅、标题净距与页脚节奏按构图分别安排，技术页标注须与当前轮廓对应；最后逐张检查并提供整组索引。制作海报不意味着授权发布或字体已成为正式发行版。

## 修订与交付

最终交付按本次范围给出字体文件、源文件/构建入口、规则与字符清单、网格和无网格样张、试排工具、版本/变更与测试记录。完整发行包装见工程参考；没有确认的名称与分发许可不替用户决定。

交付前检查本轮反馈：可复用方法写回本 skill 对应资源；当前字体的数值、品牌意见和未认可造型只留项目。只对已验证内容报告完成，不因规则写入就宣称另一套字体也已验证。
