# 覆盖范围与按需专项

用于判断“本项目完整”需要做什么，不把所有字体门类自动加入每次委托。主流程继续使用 SKILL.md 的需求、研究、选样、控制字、扩字、光学审校、工程、交付与维护；本页补充触发条件和需额外取得的证据。

## 先确认完整性的范围

- 记录字体用途/类别、明确字符与语言、字重/字宽/斜体或轴实例、目标尺寸、横竖排、桌面/网页格式、所需功能和目标应用。专业符号、图标或仅有字标的任务另定语义与覆盖，不假定它们都是完整文本字库。
- 在[项目规则表](../assets/design-rules-template.md)列出每个适用项、检查方式与完成证据。适用项可记已检/有问题/未检；只有委托确实不需要时才记不适用。所需能力缺工具、缺语料或缺语言审阅时保留待补状态，继续独立可做的工作，不能用“不适用”掩盖缺口。
- 区分：已有操作与工具、可沿用主流程但需专门实现/审阅、现有工具未覆盖。现有脚本负责测量、声明范围内的静态字体工程检查、离线试排和技术册，并不是通用自动造字器、完整格式认证或所有文字的专业审校引擎。
- 完成以本项目必需证据为准：设计/光学、字体结构、语言与塑形、用户确认、目标平台和封装分别记录。所需专项未完成时，不以某个脚本的 PASS 宣称全项目或正式发行验收通过。

## 主流程完整性核对

需求启动时用下表建立本项目关卡，交付前回读当前证据。不是每次重做已有确认，也不是把所有专项都强加给普通标题字。

| 环节 | 负责入口/工具 | 完成证据 |
| --- | --- | --- |
| 用途、字号、语言、字符、家族和平台 | SKILL 开始与范围、规则模板 | 明确码点/功能/目标环境与验收范围 |
| 原创、衍生或混合路线 | 测量参考、中文参考、版权流程 | 继承范围、源版本/哈希、真实许可 |
| 参考研究与测量校准 | measure_reference.py | 实测/代理/unknown 分开，校准与误差 |
| 三案和确认 | SKILL 第 0 节 | 同尺度效果图与用户选定；认可母版续做沿用记录 |
| 骨架、比例、字重、字面和网格 | 规则模板、结构审校 | 真实控制字的源轮廓、网格/无网格及目标字号 |
| 控制字、试验字体与分组扩字 | 结构审校、专项生产参考 | 真实编译、按结构组扩展，语义/内白/重心/笔画分别复查 |
| 路径、闭合、方向、重叠、极值与共享依赖 | check_source.py、Fontmake、PathOps/编辑器 | 候选问题审阅、部件图、母版兼容与编译结果 |
| 边距、字偶和整体节奏 | spacing-and-kerning.md、check_font.py | 默认逐场景审校、字形判断、词句和特性开关对照 |
| i/j 回钩、下伸部与视觉嵌套 | 字距专项 | 完整横向包围与同高度间隙分开；禁止 i 落入 j 回钩形成不当嵌套，不能只看无碰撞 |
| OpenType 替换/定位与上下文 | check_specialties.py、HarfBuzz | 声明语言/脚本/方向/簇/轴/特性和真实结果 |
| 成稿全字符、组内与跨组光学 | 结构与字距审校 | 放大、目标及小一档字号、反白、真实词句、例外与确认 |
| 编码、空白、度量与结构 | check_font.py、FontBakery、OTS | 当前输入哈希、未解决 FAIL/WARN/SKIP 分开报告 |
| 内部/双语命名和家族样式 | bilingual-naming.md、name_records 预期值 | 各格式精确回读；实际应用菜单/按钮另测 |
| 版权、许可、归属与嵌入字段 | copyright-and-license.md | 确认资料写入、逐格式回读、原许可随包 |
| TTF、CFF OTF 与网页格式 | 工程封装、Fontmake、FontTools | 真实曲线/容器类型；完整容器和子集分开验证 |
| 交互试排、网格、载入及下载 | create_proof.py、check_proof.cjs | 当前版本实际载入/下载哈希，交互与浏览器证据 |
| 技术册、字符表、字号与 PDF | create_font_book.py、render_font_book.cjs | 当前字体、缺字/回退/溢出与报告新鲜度 |
| 交付清单、源、ZIP 与回读 | package_project.py | 权威源/构建入口、逐文件哈希、CRC 和 ZIP 字节一致 |
| 技术及应用海报 | promotion-posters.md，按需触发 | 当前真实字体、特性决定构图；发布另需任务授权 |
| 平台、安装更新、应用和印刷 | 专项生产第 12 项、check_coretext.swift | 实际系统/应用测试；进程注册不等于安装，PDF 不等于实物印刷 |
| 维护、回归、副本和旧版清理 | 工程维护、retire_font_artifacts.py | 同源重建、证据更新、依赖保护及授权范围内可恢复清理 |

## 12 类按需专项与可运行路径

设计动作、具体命令、技术样本、失败处理和专业审阅要求统一见[专项生产、工具与验证](specialist-workflows.md)，避免只登记“已覆盖”而没有执行入口。

| 触发条件 | 工具/实际样本 | 必须补齐的项目证据 |
| --- | --- | --- |
| 衬线、强对比、书写/装饰 | Fontmake 重建衬线家族、Dancing Script、真实样张 | 对比、衬线接合、书写连接、细节及识别审阅 |
| 多字重/宽度、斜体家族 | UFO/Designspace、family、Fontmake 兼容检查 | 骨架、重量梯度、中间态、样式分组和按钮 |
| 正文/界面小字 | ttfautohint、FreeType、opsz 实例、字号阶梯 | 实际栅格、设备、阅读与处理前后对照 |
| 多语言/地区造型 | shape_run、locl、NFC/NFD、叠加附标样本 | 逐语言真实词句和专业审阅 |
| 原创中文/地区字形 | 原创 12 控制字 UFO/Glyphs、部件依赖回归 | 按字集分组扩展、地区字形与错笔审校；不把控制字称整库 |
| 竖排/版面 | Noto CJK 垂直子集、ttb、vert/vrt2、浏览器 | 旋转、标点、混排、禁则/挤压与目标引擎 |
| 复杂文字 | Noto Arabic/Devanagari/Thai 塑形及子集对照 | 脚本规则、连接/重排/附标/簇、双向与语言确认 |
| 可变字体 | 实际编译 VF、variable 静态实例比对、多轴组合 | 轴/映射/命名实例、端点中间态和视觉碰撞 |
| 彩色/emoji/位图 | COLR v0/v1、emoji ZWJ、sbix、Canvas 像素 | 约定格式真实客户端、透明/缩放/回退及序列 |
| 等宽/代码、图标、专业符号 | mono、STIX MATH/MathML、Bravura/Verovio | 占位/语义/可访问性，真实公式或排谱及专业审阅 |
| 网页子集/体积 | FontTools subset、轮廓/塑形等价、WOFF2/HTTP | 功能依赖与许可保留、真实部署加载/回退/CORS/缓存 |
| 正式生产与平台发行 | FontBakery、OTS、CoreText 进程测试、打包门禁 | 未解决警告、真实安装/更新、目标应用、嵌入及印刷 |

技术工具已有可运行输入与失败案例；仍需人的设计与语言判断。实际支持的格式/引擎以工具版本和所选样本为准，不能把一个门类的成功推定为整个 Unicode、全部彩色格式或所有客户端的认证。

## 交付后继续有效

按[版本维护、源与旧文件](engineering-packaging.md#版本维护源与旧文件)维护权威源、构建入口、变更记录与同版副本；清理和卸载遵守用户已有授权。不要让旧 source、旧网页字体、历史海报或其他项目依赖在下一轮悄悄覆盖当前版本。
