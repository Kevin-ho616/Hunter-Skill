# 结构审校与修订经验

用于首次控制字、扩字或收到“感觉不统一”反馈时。以下来自反复修订中识别的根因；具体字形和数值仍由本项目风格决定。

## 把风格落到几何关系

“方正”要分别检查顶底直线、侧壁直线、转角区域、切向和内白形状；只缩小一个圆角半径，可能仍有连续鼓出的侧壁。“圆润”也不意味着每个连接都套圆角。

闭合字的内外角应该看起来属于同一系统：比较弯曲开始/结束位置、转弯处笔画黑度、直立侧壁长度和负形面积。相同绝对半径放在不同宽度的碗部上可能显得不同；相同轮廓机械内缩可能挤坏字腔。按结构组设范围和相对关系，再容许光学例外。

规则写成可观察的条件，例如“这组字保留平直侧壁，曲率集中在转角；小碗的转角范围略收缩”，比“所有角统一 80 u”可迁移。只有当前项目已确定数值后，才添加数值断言。

平顶、平底与光学超出要分别判断。大面积水平极值不能直接沿用圆体的超出量；用同尺度 H/O、n/o、0/O 比较后决定是否贴合基准线，并记录用户确认。检查 b/d/p/q 等竖笔与碗部在基线、小写线的拼接，避免部件高度差造成台阶。修正共同母版后同步附标字、组合字和相关符号；保留有意义的尾部、下伸部与附标。此规则不意味着所有曲线、尖顶或所有字体都取消光学超出。

明确要求规整的**圆形转角**时，采用相切的直线与四分之一圆，并核对切向及实际内外半径；横纵拉伸的椭圆和自由贝塞尔不能仅凭“看起来圆”视为符合要求。几何等线宽的圆角框，其同心内外半径差应等于笔宽；按大碗、小碗等结构组选择半径，空间不足先改结构。此关系只约束本来就要求恒厚偏移的框，不取代其他字体的独立内白与光学校正。

## 网格的两个尺度

- 源设计用真实 UPM、基线和坐标；所有字保持同一缩放。不要按单字框拉满，使窄字和宽字被悄悄拉伸。
- 浏览器工具按 1 em = 1000 显示归一单位。原字体若为 2048 UPM，须乘 1000/2048；显示单位不能冒称原始坐标。
- 字面框是黑色轮廓的范围；占位宽是排版前进量；边距是二者相对原点的关系，允许负边距。辅助线移动不能改变字形或字体度量。
- 网格先于批量扩字；无网格的实际单词和段落同时存在。逐码点网格不验证连字、组合附标定位或复杂塑形。

## 分组检查

| 结构组 | 重点观察 | 容易出现的误修 |
| --- | --- | --- |
| H/E/F/I/L/T | 竖横黑度、端头、横笔位置 | 未区分几何等线宽与视觉等重 |
| O/B/D/P/R/Q | 平直段、内外角、上下碗、内白、腿/尾连接 | 用连续圆弧代替方正侧壁；小碗直接复制大碗 |
| C/G/c/e | 开口大小、方向、端头、G/e 横笔连接 | 矩形挖口破坏局部厚度；收口后堵住负形 |
| S/s/8/3 | 腰部、上下体积与重心、端头、最窄内白 | 未按项目选择几何恒宽或光学等重；强制旋转对称；只改宽度 |
| A/M/N/K/V/W/X/Y/Z | 斜笔实际厚度、交汇黑度、腿和顶点 | X 交点减重过度，腰变针；横向压缩整个字 |
| n/h/m/r/u | 肩部平直/转弯规则、竖笔节奏、内白 | m 叠两个 n 出中缝/过黑；u 镜像后不复看 |
| a/e/g/b/d/p/q | 本身结构、字腔、开口、伸部与钩 | 从大写缩小；把 a/g 做成无辨识度的 o 变体 |
| 0–9 | 数字组与字母的风格、等宽占位、价格和列对齐 | 使用惯常圆润数字破坏既定风格；未确认同形关系就将 6/9 直接旋转 |
| 2/4/5/6/9 | 2/4 斜线两侧/切向；5 开口；6/9 的重心与出口 | 斜笔连接产生楔形、凹口；收口堵塞 |
| &/@/?/ß/§/¶ | 识别、内白、连接重量、目标尺寸 | 以缩放字母拼接复杂符号，或只查示例里的符号 |
| æ/œ/Æ/Œ | 共享连接的粗细、内白、节奏 | 两个完整字叠合导致中部过黑、接缝 |
| €/$/£/¥/%/‰ | 横杠出口、竖笔和圆点重量、视觉中心 | C 收口规则直接传播到 €，双横杠封死开口 |
| ©/®/™/括号/运算符 | 语义结构、字号层级和视觉中心 | 将所有圆框都改方，或所有符号都拉到字高 |
| 重音/附标 | 与窄字宽字的关系、上方余量、邻字碰撞 | 所有附标同宽同位置；只检查单字不检查字偶 |

## 闭合字腔接竖笔与同类字形对齐

闭合碗部接入竖笔时，分别检查包围字腔的外轮廓、内部白腔和竖笔。内腔已经共享或几何相同，不能证明外侧转角完整；部件拼合、布尔并集或直角连接可能填平原有斜切，留下过重黑块。先与已确认母字同尺度比较，定位是外角缺失、重叠过多，还是字腔本身的问题。

- **折角完整性与连接黑度**：检查接头的转角起止、平直段、局部笔面和角部余白是否延续本字体的造型。折角体系需要时恢复完整外角或适当缺角，圆滑体系检查曲线连续与黑度；优先调整接合位置、转角和重叠，不能误挖内腔、切断竖笔或把整条主笔变细。几何等线宽项目仍须遵守其笔宽硬约束。
- **同类字形的对齐与结构**：按已确认共享关系展开到相关大小写、数字和符号，例如 a/e/g、b/d/p/q、6/9、@。明确哪些端头、峰顶、横笔或肩部应当共线，再对照各自基线、大写线、小写线和视觉中心。需要抬高 W/w 等峰顶时同步调整内侧折点，复核斜笔法线厚度与交汇黑度，避免只抬外轮廓而增粗；不因此默认所有字体的中峰都必须齐平。
- **修后证据与保护**：在源轮廓与每种实际导出中，同 em 查看接头放大图、目标字号与较小一档、正反白及同组混排。记录外角、内白、主体笔宽、关键高度、关联字组与保留例外；用局部轮廓差、截面和布局数据辅助核对，保护未授权改变的内腔、字宽、边距与字偶，必要的连带变化须说明。不能只修箭头所指的单字，也不能用面积数值代替视觉黑度判断。

有意的直立内壁（如部分 B/D/P/R 骨架）、三角字腔、圆滑连接、低中峰和光学超出按其已定规则保留；不为形式统一一律挖三角缺口、旋转同形或拉到同高。具体缺角尺寸、峰顶高度和字形变换关系只写入项目规则。

## 修改一个字，复查一个系统

包围符号要与实际文字一起审：用大写、小写含下伸部、数字三类混排比较顶底、视觉中心与字面宽。成对同高或镜像一致只证明符号彼此一致，不证明相对内容居中。采用大写字高框还是覆盖下伸部的包围框，应按目标用途和用户选择记录，再用实际源边界与真实导出验证；不能只检验一组孤立的括号坐标。

收到“基础造型不统一”或连续的局部标记时，先列当前已确认的母字、共享内腔/转角/端头、关联字组与光学例外，再修改源轮廓。同一造型尽量复用同一源部件或构造规则；不要仅按箭头修单字，却让相关字继续沿用旧规则。复查必须覆盖字母、数字和标点，并按点号、引号、运算符和包围符号分别核对高度与视觉中线。

仅对已确认的同构关系验证平移、镜像或旋转后的轮廓；可用几何差、度量和真实同尺度排样作证据。成对标记先核对开闭语义与方向，不能以外框同高或左右镜像代替正确造型。源稿对称还须复核真实导出；若整数取整导致偏心，检查中心落点、边距以及实心与内白，并仅在确认根因后调整原点或占位。用户明确选择成对同形时沿用该选择；未经确认不能把所有内腔、6/9 或 b/d/p/q 强行同形。B/P 的直立内壁、符号语义和必要的光学差异应列为有理由的例外。通过某个关系断言不等于整套字体的视觉一致性已获认可。

设计明确要求“完全对称”时，先写清需要成立的变换。四向等价或旋转对称不能只检查水平、垂直镜像，还须按约定核对对角线反射和旋转后的重合；源轮廓及每种真实导出分别验证，并用同尺度样张复看端面、内角与笔重。若字宽或比例保护与所需对称关系冲突，先说明并记录取舍，不能靠拉伸样张掩盖。仅要求左右对称、斜体、光学补偿或刻意不对称的设计，按各自约定检查，不自动强制正方形字面或四向对称。

先确定参考版本和保护范围，再修改源轮廓。每轮记录：

1. 反馈 → 违背的规则 → 修改理由，不用重画整套字体掩盖单点问题。
2. 直接字符与所有派生字符。共享部件要可追踪，但允许符号独立设计。
3. 源轮廓、实际 TTF/OTF、同尺度前后图；曲线转换可能改变切向或产生细小伪影。
4. 受影响的宽度、边距、字偶与附标位置。字偶数量没变不代表数值没变。
5. 保护项按规范化轮廓、hmtx 和实际布局数据比较。文件总哈希会受版本与时间戳影响，不适合证明只有某个字变化。

一个字的好看不能代替组内统一；组内统一不能代替大小写数字符号混排。先查组内，再看 `Ss O0o B8b Dd Pp Qq Rr Uu`，最后看全覆盖样张。新的大写协调不应重置已经认可的小写和数字。

## 样张与判断

- 至少覆盖放大结构、目标字号和更小一档；需要时黑白反相。字号由用途决定，不把某次使用的 48/96/192 px 固化为通则。
- 初稿、导出与比较图保留同高比例，不拉伸去追求像素重合。图像重合度、对称性或轮廓面积只能辅助诊断。
- 全字符样张按 Unicode/字形名逐页标记，含未编码替代字形和空白行为的独立检查；不能用一个英文全字母句代表数字、附标和特殊符号已检。
- 反白、下伸部与重音检查画布边界；截图不得截断而掩盖设计/度量问题。真正的字体轮廓不由截图后期修改。
- 用户说“更接近小写 s”时，传递的是平直段、转角、端头和黑度关系；大写 S 仍需按自己的比例独立调形。

## 成稿整体光学审校（必做）

每次新字体或字形修订达到可交付成稿后，在封装前单独执行本关。已有分组构建检查仍要保留，但不能只复看改动字，或用工程全绿代替整套视觉审阅。

1. **锁定实际成稿**：记录源、真实导出、试排的版本与字体哈希，留旧基线；所有比较用相同 em、基线及真实字宽，不逐字缩放拉齐。先核对约定字符清单，逐页审阅全部字形；未编码替代字形、空白和缺字行为另列，不能用一个全字母句证明覆盖。
2. **先逐字，再组内、跨组**：沿本页结构分组逐个查看骨架、识别与局部；再将有相同构造的字同排，比较上下体积、内白、切角、端头、开口、肩部、交汇及腿尾。沿母字/部件依赖查派生字；大小写、数字、标点都要覆盖，保留不同语义所需的结构。
3. **复核视觉中心与比例**：同时看黑色笔面、上下/左右内白、横笔位置和实际混排，不只看外框中点。核对窄/标准/宽字组、数字列、符号与内容的高宽关系。点号、引号、运算符、包围符号分别审位置；成对镜像不证明相对内容居中。
4. **复核光学笔重与细节**：比较竖、横、斜笔和交汇处的视觉黑度；直线斜笔沿法线测厚，不能拿水平投影充当笔厚。明确要求笔直的斜主干时，另核对中心线及两侧长边的共线性；等线宽曲线也能通过测厚，不能据此判为直笔。源骨架用直线段，并在实际导出中沿同一预期直线检查多个截面的两侧位置；圆头、交汇邻域单列，M/N 等有意波形不套用此项。需要恒厚的直斜笔再核对内外边平行、接头无意外膨胀或细颈。设计意图为等宽的直线切缝或镂空通道，另沿法线测起点、中点、终点，分别确认镜像关系、边线平行与沿线宽度；源轮廓、各真实导出和缩放派生字均复核，坐标量化误差与设计渐变分别记录。有意楔形切口和曲线开口按其规则审查，不强制等宽。曲线、锥形、笔画对比与有意减重独立判断，不强行等数值。逐组比较内腔、切角、角部余白和共享的小部件，避免单字细节仍留旧规则。
5. **用真实排版复看**：提供全覆盖无网格字板、同尺度源网格、放大细节、目标字号与较小一档、黑字白底与反白；加入真实单词/段落、跨组对照、数字价格/时间，以及括号、引号、点号和运算符混排。观察字距、负形堵塞、细节消失、相邻碰撞及行盒剪裁。放大好看不等于目标尺寸成立。
6. **逐组落记录并闭环**：在项目写明已查看字符、字号、样张路径、问题/根因、修改与保护范围；无须修改的组也给结论。S/3 的腰线、B 的上下碗、点号/尾部/附标的语义位置等，可保留但要写理由，不把统一做成机械对称。修正后重建当前导出、样张与试排，重新审阅受影响依赖和整套混排，再核对未改字形/度量/特性。

完成证据应同时包含视觉审阅记录和实际样张；数值断言、轮廓面积、对称性与自动化报告只作辅助。未解决问题、未看字号/字符/平台须真实标明；字体作者的审校与用户审美确认分别记录。纯文档、封装或工具界面改动可以复用同哈希字体的既有记录，不虚构又做过一次逐字检查。

## 来源与适用边界

网格前置的启发来自学良的[《如何用网格轻松设计字体》](https://www.sohu.com/a/234040185_505826)（学ui网转载，2018-06-04）：先看结构，再用格数比较笔画与留白。本文的拉丁字体工程与修订规则来自实际项目验证，不把文章的图形字示例当完整字体制作规范。

路径的节点、切线、方向与极值问题可核查 [Glyphs — Drawing good paths](https://glyphsapp.com/learn/drawing-good-paths)。边距先于字偶、在目标尺寸看节奏可核查 [Glyphs — Spacing](https://glyphsapp.com/learn/spacing)。这些资料不规定某一种字体必须采用的圆角或字宽。
