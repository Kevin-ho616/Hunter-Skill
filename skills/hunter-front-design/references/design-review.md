# 结构审校与修订经验

用于首次控制字、扩字或收到“感觉不统一”反馈时。以下来自反复修订中识别的根因；具体字形和数值仍由本项目风格决定。

## 把风格落到几何关系

“方正”要分别检查顶底直线、侧壁直线、转角区域、切向和内白形状；只缩小一个圆角半径，可能仍有连续鼓出的侧壁。“圆润”也不意味着每个连接都套圆角。

闭合字的内外角应该看起来属于同一系统：比较弯曲开始/结束位置、转弯处笔画黑度、直立侧壁长度和负形面积。相同绝对半径放在不同宽度的碗部上可能显得不同；相同轮廓机械内缩可能挤坏字腔。按结构组设范围和相对关系，再容许光学例外。

规则写成可观察的条件，例如“这组字保留平直侧壁，曲率集中在转角；小碗的转角范围略收缩”，比“所有角统一 80 u”可迁移。只有当前项目已确定数值后，才添加数值断言。

平顶、平底与光学超出要分别判断。大面积水平极值不能直接沿用圆体的超出量；用同尺度 H/O、n/o、0/O 比较后决定是否贴合基准线，并记录用户确认。检查 b/d/p/q 等竖笔与碗部在基线、小写线的拼接，避免部件高度差造成台阶。修正共同母版后同步附标字、组合字和相关符号；保留有意义的尾部、下伸部与附标。此规则不意味着所有曲线、尖顶或所有字体都取消光学超出。

## 网格的两个尺度

- 源设计用真实 UPM、基线和坐标；所有字保持同一缩放。不要按单字框拉满，使窄字和宽字被悄悄拉伸。
- 浏览器工具按 1 em = 1000 显示归一单位。原字体若为 2048 UPM，须乘 1000/2048；显示单位不能冒称原始坐标。
- 字面框是黑色轮廓的范围；占位宽是排版前进量；边距是二者相对原点的关系，允许负边距。辅助线移动不能改变字形或字体度量。
- 网格先于批量扩字；无网格的实际单词和段落同时存在。逐码点网格不验证连字、组合附标定位或复杂塑形。

## 分组检查

| 结构组 | 重点观察 | 容易出现的误修 |
| --- | --- | --- |
| H/E/F/I/L/T | 竖横黑度、端头、横笔位置 | 用同一数值厚度代替视觉等重 |
| O/B/D/P/R/Q | 平直段、内外角、上下碗、内白、腿/尾连接 | 用连续圆弧代替方正侧壁；小碗直接复制大碗 |
| C/G/c/e | 开口大小、方向、端头、G/e 横笔连接 | 矩形挖口破坏局部厚度；收口后堵住负形 |
| S/s/8/3 | 腰部、上下体积与重心、端头、最窄内白 | 用恒宽中心线描边；强制旋转对称；只改宽度 |
| A/M/N/K/V/W/X/Y/Z | 斜笔实际厚度、交汇黑度、腿和顶点 | X 交点减重过度，腰变针；横向压缩整个字 |
| n/h/m/r/u | 肩部平直/转弯规则、竖笔节奏、内白 | m 叠两个 n 出中缝/过黑；u 镜像后不复看 |
| a/e/g/b/d/p/q | 本身结构、字腔、开口、伸部与钩 | 从大写缩小；把 a/g 做成无辨识度的 o 变体 |
| 0–9 | 数字组与字母的风格、等宽占位、价格和列对齐 | 使用惯常圆润数字破坏既定风格；6/9 直接旋转 |
| 2/5/6/9 | 2 斜线两侧/切向；5 开口；6/9 的重心与出口 | 斜笔连接产生楔形、凹口；收口堵塞 |
| &/@/?/ß/§/¶ | 识别、内白、连接重量、目标尺寸 | 以缩放字母拼接复杂符号，或只查示例里的符号 |
| æ/œ/Æ/Œ | 共享连接的粗细、内白、节奏 | 两个完整字叠合导致中部过黑、接缝 |
| €/$/£/¥/%/‰ | 横杠出口、竖笔和圆点重量、视觉中心 | C 收口规则直接传播到 €，双横杠封死开口 |
| ©/®/™/括号/运算符 | 语义结构、字号层级和视觉中心 | 将所有圆框都改方，或所有符号都拉到字高 |
| 重音/附标 | 与窄字宽字的关系、上方余量、邻字碰撞 | 所有附标同宽同位置；只检查单字不检查字偶 |

## 修改一个字，复查一个系统

先确定参考版本和保护范围，再修改源轮廓。每轮记录：

1. 反馈 → 违背的规则 → 修改理由，不用重画整套字体掩盖单点问题。
2. 直接字符与所有派生字符。共享部件要可追踪，但允许符号独立设计。
3. 源轮廓、实际 TTF/OTF、同尺度前后图；曲线转换可能改变切向或产生细小伪影。
4. 受影响的宽度、边距、字偶与附标位置。字偶数量没变不代表数值没变。
5. 保护项按规范化轮廓、hmtx 和实际布局数据比较。文件总哈希会受版本与时间戳影响，不适合证明只有某个字变化。

一个字的好看不能代替组内统一；组内统一不能代替大小写数字符号混排。先查组内，再看 `Ss O0o B8b Dd Pp Qq Rr Uu`，最后看全覆盖样张。新的大写协调不应重置已经认可的小写和数字。

## 样张与判断

- 至少覆盖放大结构、目标字号和更小一档；需要时黑白反相。字号由用途决定，不把某次使用的 48/96/192 px 固化为通则。
- 初稿、导出与比较图保留同高比例，不拉伸去追求像素重合。图像重合度、对称性或轮廓面积只能辅助诊断。
- 全字符样张按 Unicode/字形名逐页标记，含未编码替代字形和空白行为的独立检查；不能用一个英文全字母句代表数字、附标和特殊符号已检。
- 反白、下伸部与重音检查画布边界；截图不得截断而掩盖设计/度量问题。真正的字体轮廓不由截图后期修改。
- 用户说“更接近小写 s”时，传递的是平直段、转角、端头和黑度关系；大写 S 仍需按自己的比例独立调形。

## 来源与适用边界

网格前置的启发来自学良的[《如何用网格轻松设计字体》](https://www.sohu.com/a/234040185_505826)（学ui网转载，2018-06-04）：先看结构，再用格数比较笔画与留白。本文的拉丁字体工程与修订规则来自实际项目验证，不把文章的图形字示例当完整字体制作规范。

路径的节点、切线、方向与极值问题可核查 [Glyphs — Drawing good paths](https://glyphsapp.com/learn/drawing-good-paths)。边距先于字偶、在目标尺寸看节奏可核查 [Glyphs — Spacing](https://glyphsapp.com/learn/spacing)。这些资料不规定某一种字体必须采用的圆角或字宽。
