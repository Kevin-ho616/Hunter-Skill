# 字体设计规则与审校基线

复制到字体项目后按实际需求填写；未决项标“候选”，不把建议值写成已确认。此表不预设方正、圆润、等宽或某个 UPM。

## 设计依据

| 项目 | 本项目记录 |
| --- | --- |
| 用途与目标尺寸 | 标题/正文/界面/标识；实际字号、屏幕或印刷环境 |
| 风格与禁止偏移 | 参考来源；保留的骨架与细节；已被替代的方案 |
| 语言与字符覆盖 | 明确码点清单、字符类别、语言、未编码替代字形 |
| 家族范围 | 字重、字宽、斜体、数字样式；本轮范围及明确排除项 |
| 交付与平台 | TTF/OTF、网页格式、可编辑源、目标系统与应用 |
| 名称与权利状态 | 工作名/发行名、来源与授权、许可是否已确认 |
| 当前认可基线 | 版本、源/导出文件、确认的字符或组、尚待审校项 |

## 每轮修订

- 版本与旧基线；用户反馈摘录；根因对应哪条规则。
- 拟修改范围；已认可、必须保持的轮廓/宽度/特性；有理由的连带变化。
- 实际变更清单：轮廓、占位/边距、GPOS/GSUB/锚点分别比较。
- 同尺度前后图；源稿与真实导出；全依赖复查；目标字号和整段混排。
- 结果：工程检查、设计确认、未决项、已测/未测平台分别写明。
