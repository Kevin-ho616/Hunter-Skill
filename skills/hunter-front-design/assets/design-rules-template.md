# 字体设计规则与审校基线

选定初步效果后复制到字体项目，或沿用已有认可母版，按实际需求填写；未决项标“候选”，不把建议值写成已确认。此表不预设方正、圆润、等宽或某个 UPM。

## 设计依据

| 项目 | 本项目记录 |
| --- | --- |
| 用途与目标尺寸 | 标题/正文/界面/标识；实际字号、屏幕或印刷环境 |
| 风格与禁止偏移 | 用户确认的风格与参考来源；保留的骨架与细节；已被替代的方案 |
| 初步三案与选择 | A/B/C 概念图路径与差异、用户选定编号/组合要求；沿用母版或明确跳过/代选时记录依据 |
| 语言与字符覆盖 | 明确码点清单、字符类别、语言、未编码替代字形 |
| 家族范围 | 字重、字宽、斜体、数字样式；本轮范围及明确排除项 |
| 交付与平台 | TTF/OTF、网页格式、可编辑源、目标系统与应用 |
| 名称与权利状态 | 工作名/发行名、来源与授权、许可是否已确认 |
| 当前认可基线 | 版本、源/导出文件、确认的字符或组、尚待审校项 |
| 制作路线与测量证据 | 逐字原创／开源改造／混合；参考、校准与测量报告路径，实测／推算／未知及误差范围 |
| 共同参数与自动校样 | font-targets.json；验收报告、交互试排和技术字样册版本／字体哈希；阶段稿或成稿状态 |
| 展示制作范围 | 技术展示与使用场景海报的目的、数量、渠道；字体特性如何决定文案、构图和材质 |

## 每轮修订

- 版本与旧基线；用户反馈摘录；根因对应哪条规则。
- 拟修改范围；已认可、必须保持的轮廓/宽度/特性；有理由的连带变化。
- 实际变更清单：轮廓、占位/边距、GPOS/GSUB/锚点分别比较。
- 同尺度前后图；源稿与真实导出；全依赖复查；目标字号和整段混排。
- 结果：工程检查、设计确认、未决项、已测/未测平台分别写明。
- 测量与构建参数是否更新；字体哈希变化后重跑受影响验收并重生成技术册／交互试排。报告和册页不得沿用另一版字体的通过状态。

## 成稿后的整体光学审校（必填）

新字体或字形修订成稿后、封装前填写；纯文档/封装/工具界面改动可引用同哈希字体的已完成记录。工程报告不能代替视觉审阅。

- 当前实际字体版本/哈希；源、导出、试排与旧基线；已审字符/字形清单及数量；未编码替代字形、空白与缺字的检查方式。
- 样张路径与实际观看字号：全覆盖同 em 字板、源网格、放大细节、目标字号与较小一档、正反白、字母/数字/标点混排。
