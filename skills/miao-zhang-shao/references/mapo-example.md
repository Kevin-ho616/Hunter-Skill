# 麻婆豆腐：下一轮夸张与快节奏试片骨架

这是把原型方法转成新默认的策划示例，尚未按这些新时长重新生成。常规段从原8秒先试7秒，复杂笑点从原10秒先试8秒；15段生成目标合计110秒，最终剪辑长度以产物为准。用户指定总时长时重新规划，不固定每道菜都15段或110秒。

| 段 | 工序与黑猫的更夸张表现 | 白猫与工序回收 | 生成目标 |
|---|---|---|---|
| 01 | 白猫摘成熟豆荚；黑猫抱整株猛拽，松脱后倒栽空篮，只剩两腿蹬动 | 白猫回头，轻放一只豆荚在篮沿，随后仍带回黄豆 | 7秒 |
| 02 | 黑猫把豆荚袋当鼓越拍越急，圆黄豆弹起成小扇面，空荚落头上还想装没事 | 白猫用提前入画的竹筛接住豆，剥荚成果保留 | 7秒 |
| 03 | 淘洗时黑猫捞壳像划船，水甩到鼻子，夸张僵住 | 白猫稳住筛；盖盆→夜晚→清晨泡涨豆，明确时间变化 | 7秒 |
| 04 | 黑猫骑上磨柄偷懒，转一圈回来还一本正经；白猫一停，它立刻下地装推磨 | 真正泡豆入磨眼、细豆浆出磨嘴；不拍整粒黄豆从磨嘴流出 | 8秒 |
| 05 | 黑猫挤滤布越使劲，溅出对称白胡子，它努力舔却够不到 | 白猫递布擦脸；只完成过滤，仍是豆浆与豆渣 | 7秒 |
| 06 | 黑猫扇火过猛，泡沫升高后拿蒲扇挡脸，只露金眼 | 白猫减火搅拌、撇沫，保持煮熟豆浆 | 7秒 |
| 07 | 黑猫拿大勺急着搅，白猫用小勺精准挡住它，黑猫转为抱盖 | 点卤、轻搅、静置；揭盖只能出现软豆花 | 7秒 |
| 08 | 黑猫抢当压重，像坐王座般挺胸；板偏后乳清冲出，它惊得蹦起又坐回去 | 白猫扶平板，黑猫的体重最终真的帮助压制 | 8秒 |
| 09 | 开模后黑猫按出清楚爪印，立刻藏爪、眼神四处躲 | 白猫看印再看猫，接手准备切块，不再追加随机事故 | 7秒 |
| 10 | 黑猫捧豆腐太用力，碎渣落在爪间，尴尬得两爪定住 | 白猫改让它端盘；豆腐切块并焯水 | 7秒 |
| 11 | 黑猫捣花椒后凑近闻，喷嚏把自己从小凳震下，石臼纹丝不动 | 白猫切菜不停，伸爪递手帕；备料完成 | 7秒 |
| 12 | 黑猫夸张举整筐辣椒；白猫用已在手边的筛先接住大部分，黑猫耳边挂一根还在得意 | 只加适量调料炒肉末豆瓣红油；保持后续菜品合理 | 8秒 |
| 13 | 黑猫端淀粉碗如走钢丝般紧张，眼神跟着碗沿移动 | 白猫扶爪，让它真正完成勾芡；本段以协作为主 | 8秒 |
| 14 | 黑猫偷尝烫嘴，两爪像小蒲扇急扇，看到白猫马上端坐装无事 | 白猫把米饭推过去，完成成菜展示 | 7秒 |
| 15 | 黑猫被辣得嫌小碗不够，抱大碗喝，最后倒扣头上，躲在碗沿下继续找豆腐 | 白猫扶碗，最后两猫仍一起吃到成品 | 8秒 |

每段再写成首帧与动作卡：

- 输入食物状态、场景和道具位置。
- 开始前的黑猫企图，尚未发生的事故。
- 当前段唯一主要动作与可见后果。
- 白猫的反应及输出食物状态。
- 生成秒数、预计剪辑秒数和是否需要时间跳切。
- 真实节点/任务/媒体身份留待工具回读后填写，不在策划阶段编造。

每个镜头不必比上一镜更吵。第13段保留黑猫帮上忙，第14–15段回收食物与角色欲望，让观众在更快节奏中仍有明确进展和最后的满足感。
