# 字距专项审校（默认必做）

新字体，以及字形、占位/边距、字偶、锚点或替代字修订形成成稿后，主动检查本清单，无需用户逐项指出。每次以当前真实导出、字集、语言、实例和目标字号为依据；不适用项写原因，不为检查扩大字符集、家族或功能。纯文档、封装或界面修改且字体哈希未变时，可复用同哈希记录。

## 判断原则

- 先建立单字边距，再处理特定字偶；整段 tracking 用于应用排版。组合附标、连字、连写和数学定位按各自机制判断。
- 按左字的右轮廓与右字的左轮廓分别建候选类，逐一展开成员；同一个字两侧可属不同类。a/g 的单双层、r 的端头、t 的弯脚、w 的结构、衬线、附标与替代字都可能改变关系。
- 每个候选允许收紧、放宽或保持。其他字体的已有调整、候选数量、负边距、最短轮廓距离及固定最小间距都不直接构成修改依据；机械零碰撞也不证明留白协调。
- 检查字点、主体、上伸/下伸部和装饰笔画在不同高度的空间；以目标字号中的识别与整词节奏作判断。字面框相接、视觉等距和几何等距是不同事实。

## 小写局部留白的候选组

下列组合用于主动发现问题，不是应批量添加负字偶的名单。按当前轮廓增减组员，并检查反向顺序；ve 的结论不自动适用于 ev。

| 相接结构 | 候选样例 | 观察重点 |
| --- | --- | --- |
| v/w/y 斜笔收尾 → 左圆弧 | va vc vd ve vo vq；wc wd we wo wq；ya yc yd ye yo yq | 斜边与圆弧之间的楔形留白；a/g 等特殊字形另判 |
| 右圆弧 → v/w/y | bv bw by ov ow oy pv pw py | 双向展开；右侧轮廓近似的 b/o/p 也须逐个确认 |
| 右圆弧 → x | bx ox px | 圆弧与交叉斜笔的空间 |
| 右圆弧 → z | bz oz pz | 斜向转折与横端；低频专名组合也按字集保留 |
| k 的上下斜笔 → 左圆弧 | kc kd ke kg ko kq | 上下斜臂与邻字的局部空间 |
| x 的交叉斜笔 → 左圆弧 | xc xd xe xo xq | 两端最接近处与中间留白共同观察 |
| r 的短肩 → 左圆弧 | rc rd re rg ro rq | 短肩下方空间、端头形态与邻字碰撞 |
| t 的短横/弯脚 → 邻字 | tc td te tf tg to tq ts | 上方短横与下方弯脚分别查看 |
| f 的悬出笔画 → 邻字 | fa fc fd fe fg fo fq fs | 横臂、上弯及邻字主体；必要时放宽或处理连字 |
| z 的转折 → 左圆弧 | zc zd ze zo zq | 中部与横端形成的留白 |
| e 的开口 → x | ex | 开口与斜笔的邻接 |

## 其他必查场景（按范围适用）

| 场景 | 检查样例或方法 |
| --- | --- |
| 窄字、连续字点与回钩 | ii ij ji jj il li、I/l；分开看字点、字干和 j 回钩。常规分离书写中，i 不应视觉嵌入 j 回钩；除同高度笔画间隙，另用完整横向字面范围筛查并复看整词。关闭 kern 已嵌套时查边距/悬出，仅开启 kern 才嵌套时查过度负字偶；不套固定间距，明确要求的连字/花体另判 |
| 长尾与下伸部 | gj jg gy yj Qj Qy；不能只按 x-height 区域的间距判断 |
| 易误读与密集竖笔 | rn/cl/vv 与 m/d/w，nn/mn/mm；共同判断识别、字形和留白 |
| 斜体、衬线、花体及样式交界 | f) j]、长挑笔和花体 Q/R/K/y；检查负边距、正斜体混排及段首尾，保留有意悬出 |
| 全大写与小型大写 | 全大写标题、真正小型大写及其标点单独审校；按用途判断间距，不套统一 tracking |
| 标点邻接与标点对 | r. v. w. y. P. F. T. V,、引号/撇号、括号、连字符与分隔号；逐类看语义位置及空白 |
| 附标与多语言派生字 | Tï/Tí/Tö、ďa/Ľa、VÄ/VÅ；核对 NFC/NFD、mark/mkmk、锚点及相邻碰撞，保留类例外 |
| 连字、替代字与本地化字形 | ff/fi/fl/ffi/ffl、花体、单层 a/g、locl；分别检查替换前后及替换字与左右邻字的关系 |
| 三字以上及跨词空间 | L’A、句点＋引号＋空格、f＋空格＋T/V/W；既查词距被吞，也查两侧调整叠加后的碰撞 |
| 数字、价格、时间与等宽约束 | 111/808、价格、09:41；比例与等宽数字分开；代码及等宽字保持占位/列对齐，必要时在固定框内调形 |
| 上下标、分数与数学 | x²、H₂O、1/2；专业公式按数学布局与斜体修正判断，普通字偶检查不能覆盖全部数学定位 |
| 字号、字重、字宽与可变实例 | 目标字号、较小一档、超粗/窄体、各交付字重、轴端点及必要中间状态；已有工具只验默认实例时另补检查 |
| 汉字字面疏密 | 一/人/口/国/藏等；全角字框内校正字面、重心和留白，标题比例紧排另按用途决定 |
| 中文标点与行调整 | 连续标点、开闭标点、行首尾、禁则、标点挤压、悬挂与两端对齐；按所用规范及排版引擎处理 |
| 中西文、数字及跨字体交界 | 使用AI模型、第12章、3D打印；统一交界间距策略，核对全半角、回退和跨字体运行边界 |
| 竖排 | 垂直前进量、竖排标点/括号、旋转与直立形式及垂直字偶；横排通过不能替代 |
| 连写及复杂文字 | 阿拉伯连写、印度文字音节、泰文附标等；按对应文字塑形和定位规则保持连接与字素结构，不机械逐码点插距 |

## 执行与闭环

1. **固定条件并检查基本边距**：记录字体版本/哈希、实例、字号、排版引擎、字偶/连字及 tracking 状态。先用 HH/HO/OO、nn/no/oo 和段落建立节奏，检查实际载入及缺字回退；比较额外 tracking 为零时的 kern 关/开结果。
2. **建立本项目检查池**：按 cmap 与约定功能筛选上述场景，展开实际轮廓类成员、附标、替代字和反向组合。把需排样的两字符组合写入 font-targets.json 的 shaping.pairs，把真实词句、重复串和上下文写入 samples；features 只声明项目确需实现的功能。基础拉丁需要全面量测时，可覆盖已支持字母的有序组合：小写齐全为 676 对，大小写齐全为 2704 对；不把组合数或字偶数当质量门槛，也不为中文整库机械枚举全部字对。
3. **量测与视觉分开**：利用现有 HarfBuzz 能力对比 kern 开/关，隔离无关连字/替代功能，记录字形 ID、簇、前进量和偏移；有意连字、替代字再按目标功能状态复查。检查实际相对位置及上下文，不能只看总字宽差；零变化也保留。数值、相邻空隙截面和最短距离用于筛查；缺工具或未执行项标未检，不宣称完成。现有 check_font.py 只验声明样本及工程条件，create_font_book.py 可输出 pairs 的 kern 关/开对照，均不能替代光学结论。
4. **在真实文字中审阅**：先看字偶，再看 gives words a voice、woven years、over power、make token、exercise、more tone face zero 等适用词句及项目实际文案。用同 em、真实字宽、目标字号与较小一档、放大和正反白审阅。窄字点/字干/回钩、附标、段首尾、标点和跨词空间须分别看，不用一个单词代表整组通过。
5. **按根因修正**：普遍偏松/偏紧先复查基本边距；特定组合再用类字偶与单独例外；涉及识别、笔画、连字或锚点时回到负责的字形/定位规则。根据当前字形决定收紧、放宽或保持，不复制其他字体数值，不为收紧而破坏固定宽度、连接或已认可造型。改后复查类内全部成员、上下文和相关派生字。
6. **留完成证据**：在[规则与审校模板](../assets/design-rules-template.md#字距专项审校记录默认必填)逐场景记录已检、不适用或未检及原因、覆盖组合/实例/字号、样张、量测、决定及理由。重建后核对当前源与各实际导出、试排和字样册哈希，复看受影响组和整套混排；保持不变的组也写结论。未解决的光学、语言或平台问题单独报告。

实际排样时，在离线自由试排中逐条载入 samples 并切换字偶/连字复看。技术册的字偶页提供已声明组合的对照；封面的一条样句不能代表全部词句和上下文都已检查。

## 资料与边界

- [Glyphs：Spacing](https://glyphsapp.com/learn/spacing)、[Kerning](https://glyphsapp.com/learn/kerning)：先边距后字偶，分别建立左右类与例外，并在目标字号判断。
- [Glyphs：Contextual kerning](https://glyphsapp.com/learn/contextual-kerning)：多字符、标点和跨空格上下文。
- [FontLab：Font Structures](https://help.fontlab.com/fontlab/9/articles/font-structures/index.html)：负边距、前进量与可见空间；常见字偶仍须按具体设计判断。
- [OpenType 注册特性](https://learn.microsoft.com/en-us/typography/opentype/spec/featurelist)、[MATH](https://learn.microsoft.com/en-us/typography/opentype/spec/math)：字偶、附标、连写、数字、竖排和数学各有适用机制，不自动要求实现全部功能。
- [W3C 中文排版需求工作草案](https://www.w3.org/TR/clreq/)、[CSS Text 字距规则](https://www.w3.org/TR/css-text-3/#letter-spacing-property)：中文间距、行调整与复杂文字连接按对应规则检查；草案不作为固定规范数值的替代。

这份清单规定默认主动审校与留证，不安装后台监听器，也不自动判定或修改字体。字体审校通过、工程检查通过、用户审美确认与目标平台实测分别报告。
