# 内容与页面参考

在选择手册范围、编写逐页计划或做交付检查时读取。本参考提供内容判断和一种精简结构，不规定所有品牌采用同样页数、颜色、语言或应用品类。

## 基础规范

建立“需求项目 → 页面 → 资产 → 检查结果”的覆盖表。先保留客户明确需要的项目，再按实际业务补足必要规范；不靠无限增加物件凑出“完整 VI”。

| 项目 | 页面应让使用者知道什么 | 依据与注意点 |
| --- | --- | --- |
| 品牌与标志释义 | 业务属性、受众、调性，图形如何支持这些定位 | 区分简报事实与设计解读，避免杜撰起源 |
| 标准标志 | 图形、字标、完整组合与可用版本 | 使用同一锁定母版，列出采用版本 |
| 结构与比例 | 图形边界、关键对齐、组合尺寸关系 | 测量源几何，不能以装饰性网格充当构造依据 |
| 安全区 | 单位 x 的来源、最小边界、邻近元素限制 | 标清从图形还是完整组合边界测量，建议规则注明状态 |
| 最小尺寸 | 数字端像素、印刷端毫米，测量宽度或高度 | 按相应母版验证辨识度，区分建议阈值与打样结果 |
| 标志组合 | 横版、竖版、图形独用、中英文组合的适用条件 | 只列实际存在或获准制作的版本，不擅自重排定稿字标 |
| 标准与辅助色 | 色块、色名、HEX/RGB，必要的印刷参考 | 标准取源，转换注明条件；无依据不填专色号 |
| 字体与文字层级 | 字体、字重、中英文与数字用法、替代字体 | 检查可用性、字符与授权状态，给真实文本示例 |
| 辅助图形与版式 | 延展逻辑、裁切、图文关系、可用配色与留白 | 提供可复用示例，不能只展示一张情绪图 |
| 背景适用性 | 白底、色底、反白、单色、照片底的正确使用 | 检查对比和边缘，明确需要底板或避让的条件 |
| 禁止用法 | 拉伸、旋转、改字形、换色、改比例、侵入安全区等 | 错误点要可辨认，配正确对照，按该品牌实际禁则选取 |

如果页面预算不足，优先合并有关联的内容，保留可读性和关键约束。需要删减已承诺项目时先说明影响，不能悄悄漏项。

## 应用选择

| 应用组 | 可选项目 | 应体现的规范 |
| --- | --- | --- |
| 日常办公 | 名片、信纸、信封、文件夹、工牌、胸卡 | 信息层级、Logo 安全区、字体、纸面比例 |
| 业务文档 | 报价单、订单、报告、提案、PPT 模板、邮件签名 | 栏网、表格、页眉页脚、数字与长文可读性 |
| 包装与交付 | 纸袋、包装盒、封签、快递箱、交付标签 | 正反面关系、单色工艺、折叠与粘贴区；未校核不作生产承诺 |
| 空间与导视 | 门头、前台、门牌、方向指引、展架 | 使用距离、安装背景、对比；尺寸建议与现场核测分开 |
| 数字传播 | 社交封面、头像、网站页首、活动海报 | 屏幕尺寸、裁切安全区、小尺寸识别 |
| 文创与服饰 | 笔记本、笔、杯、帆布袋、服装 | 印制位置、图形延展、材质与工艺适配 |

用户要求办公与文创样机时，两类都必须落地。其他类别按业务与简报选择。每项应用给平面设计或关键布局说明，再用场景展示材质、尺度和使用关系；同一物件的多角度不算多个应用类别。

## 约 20 页汇报示例

适合希望快速审阅品牌系统的精简汇报。用户给定页数优先；完整执行手册可按规范复杂度扩展，不能将这份例子机械当成目录。

| 页码 | 主题 | 主要画面与内容 |
| --- | --- | --- |
| 1 | 封面 | 正式品牌名称、主标志、手册名称与版本 |
| 2 | 业务与品牌定位 | 业务、受众和调性的简明关系 |
| 3 | Logo 设计释义 | 有依据的图形拆解与行业意象 |
| 4 | 视觉系统总览 | 标志、颜色、文字和图像语言的整体关系 |
| 5 | 标准标志与组合 | 实际可用的图形、字标和组合版本 |
| 6 | 结构与比例 | 以真实轮廓为准的比例及对齐标注 |
| 7 | 安全区与最小尺寸 | 计量基准、边界、数字端与印刷端示例 |
| 8 | 色彩规范 | 标准色、辅助色及有条件的印刷参考 |
| 9 | 字体规范 | 字体、字重、中文、英文和数字示例 |
| 10 | 辅助图形与版式 | 图形延展、留白与图文布局规则 |
| 11 | 背景与禁止用法 | 正确对照、错误示例及简短解释 |
| 12 | 名片 | 正反面及办公使用效果 |
| 13 | 办公文具 | 信纸、信封或文件夹的统一设计 |
| 14 | 业务文档 | 与业务有关的单据、报告或提案模板 |
| 15 | 证件应用 | 工牌或胸卡的平面与佩戴示意 |
| 16 | 包装交付 | 纸袋、包装或标签的统一关系 |
| 17 | 空间导视 | 适合该品牌的门头、前台或导视 |
| 18 | 办公场景 Mockup | 多种已设计应用在同一真实场景中的关系 |
| 19 | 文创场景 Mockup | 有明确设计的文创组合及材质表现 |
| 20 | 收束与使用指引 | 系统总览、版本及必要的资产使用指引 |

这些应用可以替换为数字传播、展会或其他更切合业务的项目，保持覆盖表一致。页数压缩时保留基本标准和用户指定的应用，不优先保留空洞章节扉页。

## 交付检查

### 源资产与内容

- 核对正式名称、英文、标志版本和采用画板。原始辅助线或编辑标记没有混入最终 Logo。
- 从同一母版核对所有正色、单色、反白和应用，特别检查负形、小字、边角与中英文比例。
- 结构数值、安全区、最小尺寸的单位及适用对象一致。原有标准、建议和待核信息没有混写。
- 检查色值与色块、字体名称与实际字形。CMYK 或专色没有虚构确定性。
- 对照逐页文案，检查错字、重复、缺页、遗漏应用和示例联系方式。

### 视觉与 PPTX

- 检查最终文件实际画布的宽高比为 16:9，页数与采用计划一致。不要仅以图片提示词或文件名推断尺寸。
- 渲染全部页面。大图看文字与标注，缩略图看整册节奏、对齐、页码、色彩与图像语言。
- 打开最终 PPTX，确认字体、换行、矢量 Logo 与图片没有因目标软件而改变。包内有文字节点或文件能解压，不等于可用编辑性。
- 在临时副本编辑规范文字或标注，保存、关闭并重新打开。图像页只能按图片移动或替换时，交付说明如实指出。
- 汇报用途在目标编辑器运行幻灯片播放，检查首尾页、页序、关键文字、图片和必要的转场。没有播放证据就记录“未验证播放”。
- 修复后重新检查受影响页面；不因验证警告擅自改掉用户已确认的品牌设计。

### Mockup 与制作边界

- Logo、字标、颜色、位置和透视可辨识，与同项平面设计一致。
- 办公、文创等承诺场景都有实际画面，不以资源清单或生成任务已提交当成完成。
- 只有平面与效果图时标明为设计示意。未做刀版、出血、材质工艺和实际尺寸校核，不声称已有可直接生产的文件。
- 输出最终 PPTX 的准确路径，保留采用资产与组装来源。只有已验证存在且可用的文件才列为交付物。
